Reverse the order and run again. Then lose the first reply. Count the server version changes and inspect both pending queues. Each run starts fresh.

Explain the outcome

The server accepts an edit only if its base version matches the current version. The first edit advances the record once. A receipt with the same operation ID lets a retry recover the original acknowledgement. The other phone keeps its draft and its conflicting edit for review. To combine the titles, a user would review both and submit a new edit based on version 2.

This browser experiment writes each phone and the simulated server to separate IndexedDB databases. It closes and reopens them after the offline edits. No network connection to a backend is involved.
