1. A round trip: the request goes to the server and the answer comes back. Each way takes the network's latency; this network's round trip is 250 ms.

  2. Your screen makes four requests, each waiting for the one before. Four trips in a row: a full second, for a few kilobytes.

  3. Now the network's bandwidth doubles. The trips take just as long. Predict: what does make it faster?

  4. Fewer trips in a row: send the three that don't depend on each other together, then the avatar. Or ask for the whole screen in one request.
