1. Objects live in the heap. Variables don't hold them; they hold references, arrows pointing at them.

  2. Some references are always in use: a running function's local variables, static fields like a singleton. These are the GC roots.

  3. Follow the arrows from the roots: every object you reach is reachable, so some code could still use it. Predict: what about the old User?

  4. No chain from any root leads to it. It's garbage, and the garbage collector frees its memory.
