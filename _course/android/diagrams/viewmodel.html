1. Keep the counter in a ViewModel, an object made to hold one screen's data. Each Activity keeps its ViewModels in a ViewModelStore: a small map, name → ViewModel.

  2. The phone turns, and the old Activity is destroyed. But first ActivityThread, Android's own code in your process, takes the store and holds it. Predict: what will the new Activity's counter show?

  3. 3. The new Activity is handed the same store, with the same ViewModel inside. Nothing crossed Binder: it all stayed in your process.

  4. When the user leaves the screen for good with Back, no new Activity is coming. The store is emptied, and each ViewModel's onCleared() runs.
