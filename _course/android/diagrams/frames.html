1. The screen is redrawn 60 times a second; each redraw is a frame, due about every 16 ms. Each frame is a message in the main thread's queue.

  2. One message takes too long. The frames behind it can't be drawn in time, and the app stutters: jank.

  3. The user taps. The touch waits in the queue too. Predict: what if it waits much longer?

  4. After 5 seconds system_server shows "App isn't responding": an ANR.
