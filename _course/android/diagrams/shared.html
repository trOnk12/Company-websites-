1. Threads in one process share its memory: both A and B can read and write count.

  2. Both want to add one. Each first reads the value: both read 5.

  3. Each adds one and writes back 6. The count should be 7: one update is lost. That's a race condition. Predict: how do you stop it?

  4. A lock makes them take turns, or give the value one owner. Android gives the screen one owner: the main thread. Others hand it a note.
