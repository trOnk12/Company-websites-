1. Inside a process, the work is done by threads: workers that run code one step after another. A process can have several.

  2. One of them is special: the main thread, at the front desk. It draws the screen and handles taps, while other threads download or calculate in the back.

  3. A tap arrives, but the main thread is busy. Predict: can a worker from the back handle it?

  4. No: taps are the main thread's job. The tap waits, and the screen seems frozen until the main thread is free.
