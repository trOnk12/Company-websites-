1. Your Kotlin compiles to DEX: instructions written for Android, not for any one CPU. That's what's inside your APK.

  2. The same APK goes to phones with different CPUs. Each CPU only runs its own machine code. Predict: so who runs the DEX?

  3. ART, the Android Runtime. It lives inside each app's process, on every phone.

  4. The simplest thing ART can do is interpreting: reading the DEX one instruction at a time. It always works, but it's slow.
