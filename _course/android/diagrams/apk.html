1. On your computer, your Kotlin compiles to DEX: instructions written for Android, not for any one CPU. That's what's inside your APK.

  2. The same APK goes to phones with different CPUs. Each kind of CPU understands only its own set of instructions, its machine code. Predict: so who runs the DEX?

  3. ART, the Android Runtime: the part of Android that runs your code. ART itself is already machine code for that phone's CPU, and it lives inside each app's process.

  4. The simplest thing ART can do is interpreting: reading the DEX one instruction at a time. It always works, but it's slow.
