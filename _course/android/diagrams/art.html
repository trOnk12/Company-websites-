1. You ship one APK for every kind of phone, so it can't hold machine code for one CPU. It holds DEX: instructions for Android's runtime, ART, a translator that lives inside each app's process.

  2. At first, ART reads the DEX line by line (interpreting): it works, but it's slow.

  3. Code that runs often is "hot". ART compiles it to machine code right now, while the app runs (JIT), and writes it in a notebook: the profile.

  4. Later, about once a day while the phone is idle and charging, the system's dex2oat tool compiles the profiled code ahead of time (AOT). Next start, it's already fast.

  5. A Baseline Profile is that notebook written in advance and shipped inside the APK, so the important code is compiled before your first launch.
