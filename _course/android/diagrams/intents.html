1. The chat app wants to call a friend. It can't reach into the phone app: they're in separate sandboxes. So it writes an Intent, a request to the town hall: "open the Phone app's call screen and call this number".

  2. The Intent goes to the town hall, system_server, by Binder, like every message to it.

  3. A call can cost money, so it needs a permission: a right an app must be granted, here by the user tapping Allow. The town hall checks its list: has Chat been granted the phone-call permission? Predict: what if it hadn't?

  4. Chat is allowed, so the town hall delivers the request, again by Binder, and the call starts in the phone app.

  5. A game without the permission asks the same: the town hall refuses.
