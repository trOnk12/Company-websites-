1. Opening an app can need three things: a process, your app's Application object (one per process, for setup the whole app needs), and the Activity on screen.

  2. Cold start: nothing exists yet. Fork from Zygote, create the Application (its Application.onCreate() runs), then the Activity. The slowest.

  3. Warm start: the process is alive, but the Activity was destroyed. Only the Activity is created again. Predict: what's left to do if both are alive?

  4. Nothing to create. Hot start: system_server just brings the screen back to the front.
