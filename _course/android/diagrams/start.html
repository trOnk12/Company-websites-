1. Opening an app can need three things: a process, one instance of your app's Application class (one per process, for setup the whole app needs), and the Activity on screen.

  2. Cold start: no process yet (never started, or Android ended it to free memory). Fork from Zygote, create the Application (its Application.onCreate() runs), then the Activity. The slowest.

  3. Warm start: the process is alive, but the Activity was destroyed. Only the Activity is created again. Predict: what's left to do if both are alive?

  4. Nothing to create. Hot start: system_server just brings the screen back to the front and moves it to resumed.
