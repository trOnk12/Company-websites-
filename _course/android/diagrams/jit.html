1. Some of your code runs over and over: it's "hot". Interpreting it every time is wasteful.

  2. So ART translates hot code into machine code right away, while the app runs: JIT, just-in-time.

  3. ART also notes the hot code in a notebook: the profile. Predict: what's the notebook for?

  4. About once a day, while the phone is idle and charging, dex2oat, a program that's part of Android, translates the profiled code and keeps it: AOT, ahead-of-time.

  5. A Baseline Profile is that notebook written by the app's developers and shipped in the APK, so it works from the first launch.
