1. When the phone starts up, at boot, Android starts one process, Zygote. It starts ART and loads (reads into its memory) the framework, Android's own code that every app uses. Then it waits.

  2. You open an app. system_server asks Zygote for a new process, and Zygote asks the kernel to fork: make a new process that starts as a copy of Zygote. Predict: what's already loaded in the copy?

  3. Everything: ART and the framework. The copy switches to your app's UID (Zygote has the power to switch to any UID; after switching, the copy can never switch back) and loads your app's code (its DEX, plus any code translated ahead of time). No waiting.

  4. Zygote did the same at boot for system_server: the town hall started as a copy too.
