1. Calls into system_server wait in its Binder buffer, an area of its memory set up by the kernel, until a Binder thread is free.

  2. Its size is fixed: about 1 MB (a megabyte, about a million bytes), shared by every call in progress, from every app. Predict: your app sends an Intent carrying a 3 MB photo. What happens?

  3. It doesn't fit, so the call fails with TransactionTooLargeException. A transaction is one Binder call.

  4. The fix: save the photo to a file and send only its name, a few bytes. The other side reads the file itself.
