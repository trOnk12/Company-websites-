1. When you install an app, Android gives it its own Linux user ID (UID), and runs it in its own process. The bank app and the game are two different "users" as far as Linux is concerned.

  2. The game tries to open the bank's accounts.db directly. The file belongs to another UID, so the kernel refuses. The game can't read the bank's memory either: it's a different process. This is the sandbox.

  3. Apps can still share, but only through official doors that the system controls, like Intents and ContentProviders. Who runs those doors? That's the town hall, in puzzle 4.
