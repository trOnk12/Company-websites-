1. Android installs each app as its own Linux user, with its own UID (user ID): its own key. Each app runs in its own process, a house with its own memory.

  2. The game tries to open the bank's file with its own key. It doesn't fit: the kernel checks the UID on every file and every process, and refuses. Predict: so how can apps share anything?

  3. Through official doors. The game writes a letter (an Intent) to the town hall, system_server, which checks it…

  4. …and delivers it to the bank if it's allowed. Apps never walk into each other's houses; the system carries what they share.
