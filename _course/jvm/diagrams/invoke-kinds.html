1. increment(7) is a static method: there is no object to call it on. The compiler emits invokestatic; the JVM runs exactly the method the constant pool names.

  2. A constructor or a super call has an object, its receiver, but must run one exact method, whatever the object's class. That's invokespecial.

  3. The rest have a receiver and the method can be overridden, so the object's class decides. Predict: all is a List; which instruction does all.add(c) get?

  4. add is declared in the interface List, so invokeinterface. c.next() is declared in the class Counter, so invokevirtual. Both pick the method from the receiver's class when they run.

  5. The fifth is different: invokedynamic names a bootstrap method, which the JVM runs once, the first time, to decide what this call does. Lambdas use it.
