1. First question: is the call linked by a bootstrap method, a method the JVM runs once, the first time, to decide what the call does? A lambda's is: invokedynamic.

  2. increment(7) is a static method: there is no object to call it on. The compiler emits invokestatic; the JVM runs exactly the method the constant pool names.

  3. A constructor or a super call has an object, its receiver, but must run one exact method, whatever the object's class. That's invokespecial.

  4. The rest have a receiver and an overridable method. The compiler looks only at the declared type of what you call through. Predict: all is declared as List; which instruction does all.add(c) get?

  5. all's declared type is the interface List, so invokeinterface. c's declared type is the class Counter, so invokevirtual.

  6. Both choose the code while the program runs, from the receiver's class: if c held a Loud that overrides next(), Loud's next() would run.
