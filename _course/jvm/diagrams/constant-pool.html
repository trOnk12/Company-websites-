1. getstatic reads a static field and pushes its value. Its offset jumps from 1 to 4: three bytes, the opcode plus two holding one number, 7. No name of a field is in the instruction.

  2. 7 is an index into the class file's constant pool, a numbered table at the start of the file. Entry #7 says: a field, described by entries #8 and #9.

  3. Entry #8 names the class that owns the field, through #10: the text Score.

  4. Entry #9 gives the field's name, weight, and its descriptor, I: the type written as one letter, I for int.

  5. ldc pushes a constant from the pool. 100000 is too big for sipush. Predict: what does entry #13 hold?

  6. The number itself. ldc copies it onto the stack. javap's comment, // int 100000, is javap following the same index for you.
