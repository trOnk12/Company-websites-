1. One run of Hot.kt, to scale: use is compiled at level 3 at 36 milliseconds, then at level 4 by C2 at 37.

  2. C2 inlined Counter's next() with no class check: class hierarchy analysis showed no loaded class overrides it. HotSpot records that assumption beside the code.

  3. Phase 2 creates a Loud, so Loud is loaded at 39 ms, and it overrides next(). Predict: what happens to use's level 4 code?

  4. Deoptimization: the recorded assumption fails, the code is retired, and a call running in it continues in the interpreter from the same instruction.

  5. use climbs again: C2 compiles it at level 4 within the same millisecond, now from a profile that has met Loud.
