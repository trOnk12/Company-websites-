1. Preparation (puzzle 11) gives every static field its default: limit is 0, shared is null. Now initialization runs the static code, top to bottom.

  2. The first line creates a Settings object, which runs its constructor before the next static line can run.

  3. The constructor computes doubled = limit * 2. Predict: which value of limit does it read?

  4. 0, the default: the line that writes 10 hasn't run yet. doubled is 0, and the object goes into shared.

  5. Only now does limit become 10. No error, no warning: shared.doubled stays 0 for the rest of the program.

  6. Write limit first and doubled is 20. A const val would work in any order: its value is copied in at compile time (puzzle 6).
