1. Code calls one.loadClass("Greeter"). A class loader is an object that finds class files and turns them into classes. one doesn't look yet: it asks its parent, app.

  2. app asks platform, which asks bootstrap: parent delegation, the request goes up first. None of them has Greeter, so each answers no, back down.

  3. Only now does one look in its own folder, plugin-out, and create Greeter. one is its defining loader, so this class is the pair (Greeter, one).

  4. A second loader, two, gets the same request and has the same folder and the same parent. Predict: does it get the same class?

  5. No. The parents still say no, so two defines its own class from the same bytes: (Greeter, two).

  6. Same name, different defining loaders: two classes. An object of (Greeter, one) is not an instance of (Greeter, two), so the cast fails.
