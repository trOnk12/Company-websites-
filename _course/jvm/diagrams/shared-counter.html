1. Two threads, each with its own frames, share one counter holding 7. Both get 7 before either writes.

  2. A calls compareAndSet(7, 8) (cas in the picture), a conditional write: the counter still holds the expected 7, so it becomes 8 and A gets true. Predict: B calls compareAndSet(7, 8). What does it get?

  3. false. B expected 7 but the counter holds 8, so nothing is written. Without the check, B would have written 8 again and lost an increment.

  4. B reads again, gets 8, and calls compareAndSet(8, 9). The counter still holds 8, so this time it returns true.

  5. The counter holds 9: both increments counted.
