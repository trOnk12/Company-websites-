1. A root is a starting point the program can always use: a local in a running method, like main's first and second, or a static field, like a shared cache.

  2. main runs second = null. One arrow to A is gone. Predict: which objects can the program still reach?

  3. The garbage collector starts at every root and follows every arrow: first and cache both reach A.

  4. Nothing ever reaches B, C or D. C and D point at each other, but no path from a root enters the pair: all three may be reclaimed.
