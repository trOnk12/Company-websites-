1. On Android, kotlinc still writes class files: the same stack bytecode as in module 2.

  2. The build then runs d8, which converts all the class files into DEX bytecode in classes.dex. DEX instructions name numbered registers instead of using an operand stack.

  3. On the way, d8 rewrites newer Java features older phones can't run, such as lambdas: desugaring.

  4. The APK goes to the phone. Predict: does the phone ever load a class file?

  5. No. ART runs DEX, dex2oat compiles it ahead of time at install, and the app's classes come from DEX through a PathClassLoader, the class loader Android uses for apps.
