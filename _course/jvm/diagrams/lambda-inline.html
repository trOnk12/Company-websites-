1. On the left, invokedynamic runs. The first time, its bootstrap method creates a class for the lambda. Each run then returns a function object of that class, holding the captured value, step = 7.

  2. invokestatic passes that object to runLater, which calls its invoke() with invokeinterface. invoke() runs the lambda's code, compiled into a private method of main's class.

  3. On the right, runNow is an inline function: kotlinc copies its body into each caller. Predict: what does main contain for this call?

  4. The lambda's body itself, copied into main: read System.out, push step, call println. No function object, no call to runNow.

  5. Before Kotlin 2.0, a lambda like the left one got its own class file instead, created with new. Kotlin 2.0 switched to invokedynamic, which keeps the app smaller.
