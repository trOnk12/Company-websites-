# Verifiable engineering skills map

This map tracks the requested path from first principles to work another engineer can reproduce. A published explanation is evidence of coverage. Professional readiness additionally requires an independent run, retained evidence and a changed condition that the learner can diagnose without the worked answer.

Status meanings:

- **Taught**: the portal explains and checks the concept.
- **Runnable**: a local exercise executes the mechanism and asserts an outcome.
- **Transfer**: the learner changes one condition and defends the new result.
- **Field evidence open**: the remaining check needs a device, broker, container runtime or production-like environment that the repository cannot honestly simulate.

## Completion rule

An area is complete for this portal only when every acceptance statement above has a linked fixture or captured run, the learner can repeat it from a clean environment, and a reviewer can change one assumption without invalidating the instructions. Device- or infrastructure-specific evidence stays explicitly open until it is actually collected.
