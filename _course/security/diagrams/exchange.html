1. Each side picks a random number and keeps it: its private value.

  2. From it, each makes a public value and sends it openly. The listener hears both.

  3. Each combines its own private value with the other's public value. Predict: do the two sides get the same number?

  4. Yes: the shared secret, never sent. The listener, with only public values, can't compute it. This is a key exchange.
