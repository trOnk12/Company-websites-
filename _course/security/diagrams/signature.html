1. The server has a key pair: a private key it never shows, and a public key anyone may have.

  2. It hashes the data and locks the digest with its private key: a signature.

  3. Your app checks it with the public key. It only checks out if the private key made it and the data is unchanged. Predict: but whose public key is it?

  4. A certificate says so: the server's name and public key, signed by a certificate authority whose key your phone already trusts.
