1. One key, and both sides have it: lock with it, unlock with the same key. That's symmetric encryption.

  2. The standard, AES, cuts the data into blocks of 128 bits, 16 bytes each.

  3. It scrambles every block with the key, in a way only the same key can undo. Fast enough for everything you send. Predict: what's the catch?

  4. Both sides need that key. Send it over the line, and the listener copies it, then decrypts everything.
