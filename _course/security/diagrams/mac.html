1. The sender computes a MAC from the message and the shared key, and attaches it as a tag.

  2. The receiver has the same key: it recomputes the MAC and compares. Equal: unchanged.

  3. An attacker changes the amount, but has no key. Predict: can it make a matching tag?

  4. No: the receiver's tag won't match, and the message is rejected. HMAC is the usual recipe.
