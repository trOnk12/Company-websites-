1. Data is bits; a key is bits too. Line them up.

  2. XOR them: 1 where the bits differ, 0 where they're equal. The result is gibberish.

  3. XOR with the same key again, and the data comes back exactly. That's a cipher. Predict: what if the key is used twice?

  4. XORing the two ciphertexts cancels the key: a one-time pad must be used once. Real ciphers make a fresh keystream instead.
