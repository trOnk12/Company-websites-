1. Your prompt is cut into tokens: whole words, pieces of words. "Summarise" might become two, depending on the model.

  2. The model reads every token so far and picks one next token: next-token prediction.

  3. That token is appended to the text, and the model runs again on the longer text. Predict: what does that mean for long answers?

  4. Each new token is one more step. A 300-token answer is 300 runs, which is why long answers take longer.
