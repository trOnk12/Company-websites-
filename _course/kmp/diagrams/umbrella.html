1. Three shared modules, shipped as three frameworks. Each one is imported separately by the iOS app.

  2. But each framework carries its own Kotlin runtime and its own copy of every class: to Swift, one framework's User isn't the other's.

  3. So ship one umbrella framework: all the modules, one runtime. Predict: what does exporting a module to Swift cost?

  4. An exported module comes in whole, which turns off dead code elimination for it. Export only what Swift calls; the rest is trimmed.
