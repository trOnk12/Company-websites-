  2. In a release build, dead code elimination drops the unreached blocks before LLVM runs. A debug build would keep them all.

  3. The :network module is exported, and two of its blocks are never called from Kotlin. Predict: are they dropped?

  4. No: exporting puts its whole API in the header, so Swift might call any of it, and every block stays.
