1. One Kotlin file, with the rules your app follows on every platform.

  2. The compiler turns it into something a machine can run. Its front end reads and checks your code, the same for every platform you build for.

  3. Then a back end per target. For Android: bytecode, instructions for a virtual machine. Predict: what does an iPhone, with no virtual machine, need?

  4. Native code: machine code for its own CPU, made by Kotlin/Native. Same Kotlin, same checks, two kinds of output.
