1. Both apps call the same Kotlin addition. The processor in each phone will do the arithmetic. What must happen before it can?

  2. The compiler turns the text into instructions. Its front end checks the Kotlin rules. Its back end emits instructions for the chosen target, the place you're building for.

  3. For Android, Kotlin produces class files containing bytecode, instructions a program can run. The Android build converts them to DEX. On the phone, ART reads the DEX. Predict what the iOS build gives its processor.

  4. Kotlin/Native gives iOS native code, instructions the processor can execute directly. On Android, the processor executes ART's code or the native code ART produced. Both paths end at the processor.
