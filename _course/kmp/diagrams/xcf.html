1. Each link task makes one framework for one target: one for real iPhones, one for the simulator.

  2. A processor's architecture is the instruction family it runs. iPhones and Apple-chip Macs run arm64; Intel Macs, x86-64. Predict: can one file hold both arm64 builds?

  3. No. A universal framework, merged with lipo, holds each architecture once, so only one arm64 build fits.

  4. An XCFramework doesn't merge: it keeps one framework per platform side by side, labelled device or simulator.

  5. Xcode, building for the simulator, takes the simulator's framework. A platform that isn't inside, like an Intel Mac's x86-64 simulator, gets nothing.
