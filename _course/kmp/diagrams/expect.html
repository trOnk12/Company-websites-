1. Common code makes a promise: platformName(), marked expect, with no body. It can call it without knowing how it works.

  2. Each platform keeps the promise with an actual, written with its own APIs: Android's build number, Apple's system version.

  3. When the compiler builds the Android target, it plugs in Android's actual. Predict: what if a target has no actual?

  4. That target's build fails. The compiler checks every promise is kept, so none can be forgotten.
