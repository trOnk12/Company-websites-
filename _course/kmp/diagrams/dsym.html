1. The app crashes on a user's iPhone, and iOS collects a crash report. It lists the functions that were running, as addresses in each binary.

  2. Each address is a sum: the load address, where iOS put the binary this launch, plus an offset the linker fixed. Predict: which part identifies the function?

  3. The offset: it's the same on every launch. The release build's dSYM maps offsets to functions and lines: 115188 becomes Bookmarks.add, line 12.

  4. Which dSYM? The report's Binary Images section gives shared's build UUID. The dSYM written by the same build carries the same one.

  5. A dSYM from a rebuild has another build UUID, so it can't be trusted for this crash. Keep the dSYM of every build you ship.
