1. The app crashes on a user's iPhone, and iOS collects a crash report: what the app was doing at that moment.

  2. Its backtrace lists the functions that were running, as addresses in each binary. Predict: which function is at the highlighted address?

  3. Nothing on the phone knows. The release build's dSYM file does: it maps those addresses to functions and lines.

  4. With it, the address becomes Bookmarks.add, in Bookmarks.kt, line 12. That translation is symbolication.

  5. The binary and its dSYM carry the same build UUID, written by the build into both. Only that pair matches.

  6. A dSYM from a rebuild has another build UUID, so it can't be trusted for this crash. Keep the dSYM of every build you ship.
