1. Xcode builds an app in build phases, run in order, top to bottom: Compile Sources for Swift, then the linker. There's room at the top.

  2. A Run Script phase runs your shell script there, first: ./gradlew :shared:embedAndSignAppleFrameworkForXcode.

  3. The task links just one framework: the platform and configuration Xcode is building right now. Predict: where must it go?

  4. Into Xcode's derived data, the folder where Xcode keeps its own build output, embedded and signed.

  5. Only then does Compile Sources run, and Swift's import shared finds the new framework there.
