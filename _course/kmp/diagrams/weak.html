1. A screen stores a closure that refreshes it every second.

  2. The closure uses self, so it holds the screen strongly: a cycle. The user leaves; neither is freed.

  3. [weak self] makes the closure's link a weak reference: it doesn't count. Predict: what happens when the user leaves now?

  4. The screen's count reaches zero: it's freed and its deinit runs. Inside the closure, self is now nil.
