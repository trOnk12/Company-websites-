1. Kotlin/Native has compiled your shared code to native code. But it's only CPU instructions: no names, no types.

  2. So it's packed into a framework, Apple's format for a library: the compiled code plus a description of what's inside.

  3. The description is a header, written in Objective-C, the older language Swift can call directly. Predict: what does the Swift app read?

  4. The header. Swift sees your Kotlin classes as Objective-C classes, and calls the native code behind them.
