1. iOS's main thread runs a run loop: wait for work, handle it, wait again. Android calls it a Looper.

  2. Work waits in the main queue, one task at a time: touches, timers, your tasks. Android's MessageQueue.

  3. A background thread loads an image. Predict: how does the result reach the screen?

  4. It's added to the main queue with DispatchQueue.main.async, and the main thread shows it: UI only there.
