1. iosArm64's main compilation reads commonMain and iosMain. Predict: what file does Kotlin/Native write out?

  2. A klib, a Kotlin library: one zip file, built for one target. Your module gets one; so does every library.

  3. Inside, first, the code as IR: checked by the front end, but not yet machine code.

  4. Next, a description of every declaration, so other code can be checked against it without the source.

  5. And a manifest naming the one target it was built for. Predict: can an iPhone run this file?

  6. No. Later, one final build turns your klib and every library's, like Ktor's published klib, into machine code the iPhone runs.
