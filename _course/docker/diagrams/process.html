1. The kernel is the core of the operating system: the one program that runs all the others and shares out the processor, memory and files. Here it runs two processes: your shell, bash, and ps.

  2. The kernel numbers each process when it starts: its PID, process ID. ps prints one line per process, with its PID and its command.

  3. You type docker run alpine:3.20 sleep 1000. alpine:3.20 is a container image: the files the program starts from. One more process appears, PID 3393. Predict: a ps started beside sleep, inside, lists what?

  4. Only sleep and itself: bash and the first ps are out of its sight. That fence makes sleep a container: an ordinary process that the kernel keeps from seeing, and using, everything else.
