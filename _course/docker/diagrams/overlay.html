1. One unpacked layer, read-only: a lower directory. It holds motd and os-release.

  2. The overlay filesystem (OverlayFS) mounts lower directories with one writable directory above them, and shows both as one tree: merged. The process sees only merged.

  3. A process writes notes.txt. It lands in the writable upper directory, and merged shows it. Lower doesn't change.

  4. Now the process changes os-release, a file that exists only in lower, which is read-only. Predict: where does the changed os-release end up?

  5. The kernel first copies the whole file up into upper, then changes the copy: a copy-up. Merged shows the copy. Lower still says keep me.

  6. The process deletes motd. Lower can't change, so the kernel puts a whiteout in upper: here a special 0,0 device file. Merged no longer shows motd.
