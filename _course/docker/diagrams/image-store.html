1. Alpine's layer, 25f1…, arrives as a gzip-compressed tar: 3,630,321 bytes, about 3.6 MB.

  2. With the containerd image store, Docker 29's default for new installations, containerd keeps that blob exactly as it arrived, in its content store.

  3. Then a snapshotter, here overlayfs, unpacks it into a directory of plain files, 8.1 MB. That directory is a lower directory of every container from the image.

  4. docker image ls shows two sizes for each image. Predict: is the space on disk closer to the download, or bigger?

  5. Bigger: 12.2 MB on disk against 3.71 MB of content, because each layer is kept twice, compressed and unpacked.

  6. Installations upgraded from before Docker 29 keep the older storage driver, overlay2. It stores only the unpacked files: 7.81 MB for the same image on a second daemon.
