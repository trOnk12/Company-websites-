1. alpine:3.20 is one layer: a tar archive of files, 517 entries from bin/busybox to etc/motd. Unpacked in order, an image's layers give a container its root filesystem.

  2. A container adds /notes.txt and deletes /etc/motd. docker diff lists the changes: A for added, C for changed, D for deleted.

  3. docker commit packs those changes into a second layer on top. notes.txt goes in as a file. Predict: how can a tar archive say "etc/motd is gone"?

  4. With an empty file, etc/.wh.motd: a whiteout. It means "delete motd from the layers below". The motd bytes stay in layer 1; they are only hidden.

  5. Beside the layers sits the image config: how to run the image (the command /bin/sh, its environment) and the list of its layers, in order.
