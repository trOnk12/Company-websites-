1. SHA-256 turns any bytes into a 64-character fingerprint. Written as sha256:…, that is a digest: a name made from the content itself.

  2. Now change one letter: hello becomes hellp. Predict: how much of the digest changes?

  3. All of it: bf8c8341… has nothing in common with 5891b5b5…. Any change, however small, gives a different digest.

  4. Alpine's compressed layer has the digest sha256:25f1d6b1…: exactly the name of its file under blobs/sha256 in puzzle 9.

  5. Unpacked, the same layer gives another digest, 08bc4e53…: its DiffID, the name the image config lists it under.

  6. The manifest, a small JSON file naming the config and layers (puzzle 15), has a digest too: 6b8731de…, which, with the containerd image store, is notes:v1's image ID.
