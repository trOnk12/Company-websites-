1. docker pull localhost:5000/notes:stable. The engine first asks the registry which image the tag stable points at, and gets its digest back: 640e63e0….

  2. Then it fetches that image's image manifest, by digest: a small JSON file naming one config and three layers, each by digest and size.

  3. Two of those layers, 25f1… and e6e5…, are already on this machine from notes:v1. Predict: which blobs does the engine ask for?

  4. Only the two it lacks: the config, 8bce…, and the new layer, 476c…. Each blob is fetched by its digest. docker pull printed "Already exists" for the others.

  5. The registry specification tells the client to hash every blob it receives and compare the result with the digest it asked for. A mismatch means a broken or tampered download.
