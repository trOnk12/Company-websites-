1. Each process has a folder /proc/PID/ns with one link per namespace it is in. The number in a link names that namespace. These are your shell's, on the host.

  2. The same links for the container's sleep. Predict: in which rows will the two numbers be equal?

  3. Only user. pid and mnt are new, as puzzles 2 and 3 showed; net and uts are new too. Equal numbers mean one shared namespace: the user row is puzzle 5's subject.

  4. The uts row: a UTS namespace holds the hostname. In its own, the container can have its own name; Docker sets it to the start of the container's ID.

  5. The net row: a network namespace holds network interfaces, addresses and ports. The container sees only lo and its own eth0, not the host's docker0 or its eth0.
