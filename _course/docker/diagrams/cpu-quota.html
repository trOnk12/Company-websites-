1. A busy loop in a container with no limit: the kernel lets it run on a processor all the time, as long as the processor is free.

  2. --cpus 0.5 sets a CPU quota: 50 ms of processor time in every 100 ms period. Once it's used, the group waits for the next period, however idle the processors are.

  3. Now the group runs two busy threads on two free processors. Predict: in each 100 ms, how long does each thread run?

  4. About 25 ms each. The quota counts the whole group together, so two threads use it up twice as fast, and both wait the remaining 75 ms.

  5. Measured: the one-thread loop had to wait in 101 of 102 periods, and docker stats showed about 49% of one processor, with one thread or with two.
