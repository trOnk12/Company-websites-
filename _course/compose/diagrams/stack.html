1. At the bottom, the Compose runtime: the composition, its slots and the Recomposer from puzzles 0 to 2. It knows nothing about pixels.

  2. The runtime changes a tree only through an Applier: insert, move, remove a node. Compose UI plugs one in for its LayoutNodes, and does layout and drawing.

  3. foundation builds on Compose UI: Row, Column, LazyColumn, gestures. Building blocks with no look of their own.

  4. Material sits on top: a design system, ready-made components with colours, type and shapes. Predict: which layer had to change for iOS?

  5. Mostly Compose UI's outer edge, where it meets the phone: the window, the canvas, touches and text input. foundation adds a few iOS touches; the runtime and Material, none.
