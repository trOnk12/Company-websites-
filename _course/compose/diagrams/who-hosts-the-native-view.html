1. The app's own UINavigationController owns the top: the back button and the title. UIKit decides where the next screen goes.

  2. Below the bar, the controller from ComposeUIViewController: Compose draws everything here. That edge is a hosting boundary, UIKit outside and Compose inside.

  3. Inside Compose, UIKitView cuts out a region for Apple's own UITextField: a second boundary, the other way round. Compose's snapshot state query holds the text.

  4. The user types "lake". UIKit calls editingChanged, which writes the field's text into query: native to Compose.

  5. Now the user taps Compose's Clear button, which sets query = "". Predict: which arrow reaches the field?

  6. update. It read query the last time it ran, so the write marks it, it runs again, and it empties the field: Compose to native.
