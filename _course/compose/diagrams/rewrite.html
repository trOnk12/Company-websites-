1. What you write: Greeting takes a name and calls Text. A plain Kotlin function forgets everything the moment it returns.

  2. The compiler plugin adds parameters you never wrote. $composer is the Composer: the runtime's recorder, handed into every composable call.

  3. It also wraps the body in a start and an end. What the call records in between is its group. Its key comes from Greeting's name and parameters, so every call to Greeting opens a group with the same key.

  4. Column hands its $composer to Greeting, which hands it to Text: one Composer travels down every call. Predict: can an onClick lambda call Greeting?

  5. No. An onClick lambda isn't a composable, so it has no $composer to hand on, and the compiler refuses the call.
