1. count is snapshot state, made by mutableStateOf: a value holder whose every read and every write Compose watches. The screen shows 0.

  2. While Counter runs, it reads count.value: a state read. Compose notes which group was running at that moment: Counter's.

  3. A tap writes count = 1. Compose marks every group that read count, and only those. Predict: what runs again?

  4. Only Counter, from its start: the plugin made its group a restart group, one Compose can run again on its own. Screen and Header don't run.

  5. Who runs it? The Recomposer: it waits for the next frame, then runs every marked group. Three writes before that frame cause one run.
