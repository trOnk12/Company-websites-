1. The main thread works through its own line of tasks: the main queue. Slow work there would freeze the screen.

  2. So the slow task goes into another dispatch queue, a line of tasks run by GCD on threads it manages. This one is concurrent: several tasks can run at once.

  3. One of GCD's threads picks up "load image" and runs it, off the main thread. Predict: how does the image get on screen?

  4. Through the main queue: DispatchQueue.main.async, iOS's handler.post. The main queue is serial: one task at a time, on the main thread.
